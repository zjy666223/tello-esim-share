1. Tello eSIM 是什么？

Tello 是一家使用 T-Mobile 网络的美国虚拟运营商，提供实体卡和 eSIM。原文的核心判断是：如果你需要一张可以在中国也能继续通过 Wi‑Fi Calling 收发短信、接打电话的美国号码，Tello eSIM 是比较容易买、也相对便宜的一种选择。

核心特点 直接在官网买 eSIM

无需邮寄，直接购买后添加到手机即可，这也是它相比很多美国保号方案更省事的地方。

在中国可用 主要依赖 Wi‑Fi Calling

只要连上 Wi‑Fi 或另一张卡的数据网络，就能以 Wi‑Fi Calling 的方式使用短信与通话能力。

原文定位 低成本美国保号卡

原文把它视为美国保号 eSIM 里比较简单、比较便宜的路线，尤其适合人在中国但需要美国号码的人。

2. Tello eSIM 有什么用？

  • 接收美国银行、美国券商等短信验证。
  • 注册 AI 工具，如 ChatGPT、Claude。

3. Tello eSIM 套餐

原文重点推荐的是最低门槛的 5 美元月租套餐，首月加上开通费用大约 8 美元左右。

3.1 Tello eSIM 套餐内容

  • 支持 100 分钟全球通话，其中可免费拨打 全球 60 多个国家的电话。
  • 支持无限收发短信、接听电话。
  • 月租 5 美元，原文说明账单地址不在美国时通常不需要税。
  • 支持数据漫游，但需要额外充值 Pay As You Go Credit。
  • 支持携号转网。
  • 原文特别提醒：Tello 在中国没有本地合作运营商，因此想要在中国正常收发短信和电话，关键是打开 Wi‑Fi Calling。
  • 如果要在中国大陆、香港、台湾、日本等地使用国际漫游流量，需要至少充值 20 美元的 Pay As You Go Credit，而且流量很贵，20 美元大约只能用 400MB。

4. 如何购买 Tello eSIM？

原文这里讲得很细，我把它压成一个顺手可看的购买流程，同时把里面提到的工具链接保留下来。

  • 先确认你的手机支持 eSIM。如果是国行手机，可以先看 5Ber 这类 eSIM 写入工具；原文同时说明 5Ber 已失效，需要自行寻找替代写入工具。
  • 打开 Tello 官网 注册账号。
  • 选择「100 Minutes Text」+「No data」的 5 美元月租套餐。
  • 填写美国真实地址。可辅助使用 美国地址生成器 或 谷歌地图。
  • 选择 eSIM，输入 IMEI。原文给了两个 IMEI 生成器入口：苹果、安卓。
  • 填写账单地址与信用卡号后购买，成功后会显示 eSIM 二维码。
  • 原文邀请链接：https://tello.com/account/register?_referral=P3HVV448，邀请码是 P3HVV448。
  • 原文提示：一个 Tello 账户可买多个号码；付款支持信用卡、Apple Pay、Google Pay、PayPal。
  • 原文还强调：IP、账单地址和支付卡片最好匹配，减少被砍单风险。可用 当前 IP 地址检测 做辅助检查。

5. 激活 Tello eSIM

原文把激活前的准备说得很关键，我这里按步骤整理。

  • 激活前先登录 官网，设置 911 地址，路径是 My Settings → Wi‑Fi Calling → Emergency E911 Address。
  • 再设置 Security PIN，路径是 My Settings → One-time Mobile App Password。因为 Tello 的 eSIM 二维码只能扫码一次，激活失败时靠这个 PIN 才能重新换领二维码。
  • 在中国大陆激活时，需要同时满足两个条件：一是设备支持 eSIM 或有写入工具，二是激活时使用美国 IP（原文说其他国外 IP 也可以，但美国 IP 最稳）。

6. eSIM 手机激活 Tello

6.1 外版 iPhone 手机激活 Tello eSIM

  • 开启美国 IP，原文强调必须是全局模式。
  • 打开「设置」→「蜂窝网络」→「添加 eSIM」→ 使用二维码。
  • 扫描 Tello eSIM 二维码后等待激活。
  • 进入 Tello eSIM，打开「Wi‑Fi Calling / 无限局域网通话」。
  • 如果运营商位置出现「Wi‑Fi Calling」或「Carrier using Cellular Data」，就说明激活成功。
  • 相关视频：外版 iPhone 激活保姆级视频教程

6.2 外版 Android 手机激活 Tello eSIM

  • 同样先开启美国 IP，并使用全局模式。
  • 打开「设置」→「网络和互联网」→「SIM卡」→「添加 SIM 卡」→「设置 eSIM 卡」→ 扫码。
  • 等待激活后，进入 Tello eSIM 打开 WLAN 通话。
  • 当显示「WLAN 通话」或「Carrier using Cellular Data」时，表示激活成功。

7. 国行手机激活 Tello

原文这里给了两条路：买外版手机，或者走 eSIM 写入工具。后者更省钱，所以原文重点放在写入工具上。

  • 国行手机本身不支持 eSIM，无论是国行 iPhone 还是国产安卓都不行。
  • 方案一：购买外版无锁手机。原文更推荐日版或加拿大版 iPhone，因为它们是「实体卡槽 + eSIM」组合；原文明确不建议买美版 iPhone 作为国内主力机。
  • 方案二：使用 eSIM 写入工具，例如 5Ber。原文同时提醒 5Ber 已失效，应改用其他写入工具，但教程思路仍可参考：视频教程、文字教程

8. 使用 Tello eSIM

  • 在中国大陆激活后，Tello 本身没有本地信号是正常的，因为它并没有可直接连接的中国运营商。
  • 在中国使用时，主要依赖 Wi‑Fi Calling：让手机连 Wi‑Fi 或另一张卡的数据网络，然后打开 Tello eSIM 的 Wi‑Fi Calling。
  • 连接 Wi‑Fi 时，运营商通常显示为 Wi‑Fi Calling / WLAN 通话；连接另一张卡数据时，通常显示为 Carrier using Cellular Data。
  • 发短信、收短信、接电话都可用系统自带的短信 / 电话应用。
  • 拨打电话有两种方式：一是在 My Tello App 内拨打；二是在手机拨号盘中按「011 + 区号 + 电话号码」格式拨打。
  • 如果需要数据漫游，需要提前在官网开启国际漫游开关，并充值 Pay As You Go Credits。

10. Tello eSIM 常见问题 FAQ

  1. Q1. 如何拨打电话与收发短信？
    原文建议：拨打电话可以用 My Tello App，也可以用系统电话应用，但系统拨号时需按「011 + 区号 + 电话号码」格式。收发短信用系统短信应用即可。
  2. Q2. 如何数据漫游？
    登录官网后，在 My Settings 打开 Pay As You Go Data 和 International Roaming，然后充值最低 20 美元的 Pay As You Go Credits。
  3. Q3. 激活失败怎么办？
    原文说可以重新换领新的 eSIM 二维码。路径是登录官网 → My Settings 设置 Security PIN → My SIM → Get eSIM。
  4. Q4. 收不到短信怎么办？
    重新激活 eSIM 或重新激活 Wi‑Fi Calling。原文再次强调：激活时最好使用美国 IP，而且要全局模式。
  5. Q5. 如何联系 Tello 客服？
    原文给了三个入口：网页版在线客服、My Tello App 内 Contact、电话客服 +1-866-377-0294。
  6. Q6. 不想用了如何取消？
    登录官网 → Dashboard → My Plan → Cancel Plan。原文也建议考虑转入 Google Voice 作为长期保号路径。
  7. Q7. 赠送的 10 美元话费在哪？
    登录网页版官网后，点击 Referral Program 即可查看。
  8. Q8. 赠送的 10 美元如何支付次月月租？
    进入 Dashboard，点击 Renew Now，在页面底部选择 Tello Dollars 使用。原文提到手动续费后，每个月的通话时长会自动叠加。
